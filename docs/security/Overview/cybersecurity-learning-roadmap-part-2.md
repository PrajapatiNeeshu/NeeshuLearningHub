# Cybersecurity Learning Roadmap

This roadmap is designed to help you learn cybersecurity in a logical order. Do not jump to advanced topics before mastering the basics. Complete one module at a time, take notes, and practice with a lab or mini project before moving to the next one.

## How to Use This Roadmap

For each module:

1. Read the concept notes.
2. Watch the recommended course or tutorial.
3. Write a short summary in your own words.
4. Practice with a hands-on task or lab.
5. Review what you learned and write 5 key takeaways.

> The goal is not to finish fast. The goal is to build strong fundamentals and practical understanding.

---

## Phase 1: Cybersecurity Fundamentals

### Module 1: Introduction to Cybersecurity

**Objective:** Understand what cybersecurity is, why it matters, and the basic terms used in this field.

**Topics to learn:**
- What is cybersecurity?
- Why cybersecurity matters in the digital age
- Threats, vulnerabilities, and risks
- The CIA Triad: Confidentiality, Integrity, Availability
- Authentication and authorization
- Common cyber threats
  - Malware
  - Phishing and social engineering
  - Insider threats
  - DoS/DDoS attacks

**Recommended resources:**
- Microsoft Cybersecurity Fundamentals
- IBM Exploring Cybersecurity
- Fortinet Cybersecurity Fundamentals
- Cisco Introduction to Cybersecurity
- ISC2 Entry-Level Learning
- OpenLearn Introduction to Cyber Security

**Practice tasks:**
- Create a one-page note explaining CIA Triad.
- List 10 common cyber threats and describe them in 1-2 lines each.
- Explain the difference between a threat, a vulnerability, and a risk.

**Checkpoint:**
- You can explain the purpose of cybersecurity.
- You can identify the main types of threats.
- You understand confidentiality, integrity, and availability.

## Phase 2: Networking and Linux Foundations

### Module 2: Network Fundamentals

**Objective:** Learn how computer networks work and how they can be secured.

**Topics to learn:**
- Network architecture
- Client-server model
- OSI model and TCP/IP stack
- IP addressing, DNS, routing, switching
- Common network devices and services
- Network segmentation and traffic flow

**Recommended resources:**
- Cisco Networking Basics
- Microsoft Networking Fundamentals
- TryHackMe Intro to Networking
- TryHackMe DNS in Detail

**Practice tasks:**
- Draw a simple network diagram with router, switch, firewall, and server.
- Explain the OSI layers in your own words.
- Describe how DNS works.

**Checkpoint:**
- You can explain basic networking concepts.
- You understand common network devices and data flow.

### Module 3: Linux Fundamentals

**Objective:** Learn the operating system most commonly used in cybersecurity and IT environments.

**Topics to learn:**
- Linux file system basics
- Users, groups, and permissions
- Common commands
- Shell usage
- Processes and services
- Log files and troubleshooting

**Recommended resources:**
- Linux Foundation – Introduction to Linux
- TryHackMe Linux Fundamentals

**Practice tasks:**
- Practice commands such as ls, cd, pwd, chmod, chown, cat, grep, find, ps, and top.
- Create and manage a file with permissions.
- Read a system log and explain what it shows.

**Checkpoint:**
- You are comfortable navigating the Linux terminal.
- You understand file permissions and basic system administration.

### Module 4: Windows Security Fundamentals

**Objective:** Learn the security posture of Windows-based systems and common enterprise controls.

**Topics to learn:**
- Windows user accounts and groups

- Windows Defender and built-in security tools

- Security baselines

**Recommended resources:**

**Practice tasks:**

- Identify how access control and permissions help protect systems.
- Explain the importance of patching and endpoint protection.

## Final Deliverables

By the end of this roadmap, you should be able to:

- Explain the fundamentals of cybersecurity
- Understand networking, Linux, and Windows security basics
- Identify common application and network vulnerabilities
- Work with IAM and zero trust models
- Understand SOC operations and incident response
- Apply risk and compliance concepts
- Complete practical labs and document your findings

## Recommended Success Habit

Keep a personal cyber journal with:
- one concept learned per day
- one vulnerability or attack explained in your own words
- one lab summary every week
- one mini-project every month

> This is the best way to turn theory into practical cybersecurity knowledge.

## Learning Path Summary

- Start with fundamentals
- Build networking + Linux skills
- Learn network and application security
- Understand IAM and endpoint protection
- Study SOC, forensics, and incident response
- Explore compliance, risk, and cloud security
- Finish with labs and real-world practice

This roadmap gives you a complete path from beginner to practical security learner. Study one section at a time, keep notes, and practice until you can explain each concept without looking at the source.
