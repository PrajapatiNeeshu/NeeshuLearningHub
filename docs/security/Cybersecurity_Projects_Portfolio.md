# 3. Caesar Cipher Tool

## Objective

Understand basic encryption techniques through substitution ciphers.

### Features

- Text Encryption
- Text Decryption
- Custom Shift Values

### Example

Input:

```text
HELLO
Shift = 3
```

Output:

```text
KHOOR
```

### Skills Learned

- Cryptography Fundamentals
- Character Encoding
- Secure Coding Logic
