# Cybersecurity Study Tracker

Use this tracker to follow your learning step by step. Mark each module as you complete it, and write a short note on what you learned before moving to the next one.

## Study Rules

- Complete one module before starting the next one.
- Spend time on notes, labs, and review.
- Revisit difficult topics before moving ahead.
- Keep one practical lab or mini-project for each major phase.
