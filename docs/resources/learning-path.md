# Learning Path

## Beginner Phase (4-6 weeks)

### Week 1-2: QA Fundamentals
- [ ] Learn what QA is and its importance
- [ ] Understand test levels and types
- [ ] Learn test case writing
- [ ] Understand bug reporting

**Resources:**
- [QA Interview - General Concepts](../interviews/qa-interview.md)
- ISTQB Foundation Handbook

### Week 2-3: Manual Testing
- [ ] Test web applications manually
- [ ] Learn browser developer tools
- [ ] Understand HTTP requests
- [ ] Test API responses with Postman

**Resources:**
- [API Fundamentals](../api-testing/api-fundamentals.md)
- [Testing Tools](../api-testing/testing-tools.md)

### Week 4-6: Test Automation Setup
- [ ] Learn Python basics
- [ ] Install Playwright
- [ ] Write first Playwright script
- [ ] Understand selectors

**Resources:**
- [Playwright Basics](../playwright/playwright-basics.md)
- [Advanced Selectors](../playwright/advanced-selectors.md)

---

## Intermediate Phase (8-10 weeks)

### Week 7-8: Automation Frameworks
- [ ] Learn Page Object Model
- [ ] Use pytest fixtures
- [ ] Organize test structure
- [ ] Handle test data

**Resources:**
- [Playwright Best Practices](../playwright/best-practices.md)
- [Test Automation Interview](../interviews/automation-interview.md)

### Week 9-10: API Testing
- [ ] Learn REST concepts
- [ ] Write API tests with pytest
- [ ] Use requests library
- [ ] Validate JSON responses

**Resources:**
- [REST Concepts](../api-testing/rest-concepts.md)
- [Testing Tools](../api-testing/testing-tools.md)

### Week 11-12: CI/CD Integration
- [ ] Understand GitHub Actions
- [ ] Create test workflow
- [ ] Generate HTML reports
- [ ] Upload artifacts

**Resources:**
- [DevSecOps Intro](../devsecops/devsecops-intro.md)
- [CI/CD Security](../devsecops/cicd-security.md)

---

## Advanced Phase (10-12 weeks)

### Week 13-14: Security Testing
- [ ] Learn OWASP Top 10
- [ ] Test authentication
- [ ] Test authorization
- [ ] Identify vulnerabilities

**Resources:**
- [Security Basics](../security/security-basics.md)
- [OWASP Top 10](../security/owasp-top-10.md)

### Week 15-16: Performance Testing
- [ ] Load testing concepts
- [ ] Stress testing
- [ ] Monitor performance metrics
- [ ] Use locust framework

**Resources:**
- [API Testing Tools](../api-testing/testing-tools.md)
- [Test Automation Interview - Performance](../interviews/automation-interview.md)

### Week 17-18: Cloud & DevSecOps
- [ ] AWS basics
- [ ] CI/CD pipelines
- [ ] Container testing
- [ ] Security scanning

**Resources:**
- [AWS Basics](../aws/aws-basics.md)
- [DevSecOps Intro](../devsecops/devsecops-intro.md)

---

## Daily Habits

### Morning (30 minutes)
- [ ] Read one technical article
- [ ] Review code from colleagues
- [ ] Check automation test results

### Work Hours (2-3 hours)
- [ ] Write/execute tests
- [ ] Debug failing tests
- [ ] Improve test coverage

### Evening (30 minutes)
- [ ] Learn new tool/framework
- [ ] Practice coding challenges
- [ ] Review learning materials

### Weekly
- [ ] Complete one tutorial
- [ ] Write blog post on learnings
- [ ] Contribute to open source
- [ ] Mentor junior testers
