# Top 15 GitHub Profiles Every AI, ML, Data Science & Software Engineer Should Follow

A curated collection of GitHub profiles that can help you learn:

- Artificial Intelligence (AI)
- Machine Learning (ML)
- Deep Learning

- Data Science
- Python
- Software Engineering
- System Design
- Open Source Development

## 1. Wes McKinney: Creator of Pandas

[GitHub: wesm](https://github.com/wesm)

Wes McKinney is the creator of Pandas, one of the most widely used Python libraries for data analysis and manipulation.

**Learn from:** Pandas, data analysis, Python, and open source development

**Best for:** Data scientists, Python developers, and data analysts

## 2. Jake VanderPlas: Scientific Python & Data Science

[GitHub: jakevdp](https://github.com/jakevdp)

Jake VanderPlas is known for contributions to the Scientific Python ecosystem and data science education.

**Learn from:** NumPy, data visualization, scientific computing, and machine learning

**Best for:** Data science and scientific Python learners

## 3. Tirthajyoti Sarkar: Machine Learning & Python

[GitHub: tirthajyoti](https://github.com/tirthajyoti)

Explore machine learning projects, data science resources, and practical Python implementations.

**Learn from:** Machine learning, data science, and practical Python projects

**Best for:** Beginners, ML engineers, and Python developers

## 4. Andrej Karpathy: AI & Deep Learning

[GitHub: karpathy](https://github.com/karpathy)

Andrej Karpathy is an influential AI educator and researcher whose repositories make advanced AI concepts accessible.

**Learn from:** Deep learning, neural networks, LLMs, and generative AI

**Popular repositories:** [nanoGPT](https://github.com/karpathy/nanoGPT) and [micrograd](https://github.com/karpathy/micrograd)

**Best for:** AI engineers, deep learning engineers, and LLM developers

## 5. Manu Joseph: Machine Learning

[GitHub: manujosephv](https://github.com/manujosephv)

Manu Joseph is a machine learning practitioner known for practical ML implementations and educational repositories.

**Learn from:** PyTorch, machine learning, and data science

**Best for:** ML practitioners, data scientists, and PyTorch developers

## 6. Hugging Face: Open Source AI

[GitHub: huggingface](https://github.com/huggingface)

Hugging Face provides an industry-leading open-source AI ecosystem.

**Popular projects:** [Transformers](https://github.com/huggingface/transformers), [Diffusers](https://github.com/huggingface/diffusers), [Datasets](https://github.com/huggingface/datasets), and [Accelerate](https://github.com/huggingface/accelerate)

**Learn from:** LLMs, NLP, computer vision, and generative AI

**Best for:** AI developers, NLP engineers, and LLM engineers

## 7. OpenAI: AI Research & Tools

[GitHub: openai](https://github.com/openai)

OpenAI publishes AI research projects and developer tools.

**Learn from:** Large language models, reinforcement learning, and AI research

**Best for:** AI engineers, researchers, and developers

## 8. Microsoft: Cloud AI & Developer Tools

[GitHub: microsoft](https://github.com/microsoft)

Microsoft maintains thousands of repositories covering AI, cloud computing, DevOps, productivity, and security.

**Learn from:** Azure AI, Semantic Kernel, VS Code, and Power Platform

**Best for:** Cloud engineers, AI engineers, and software developers

## 9. Google: AI & Open Source

[GitHub: google](https://github.com/google)

Explore Google's open-source projects and AI ecosystem.

**Learn from:** TensorFlow, JAX, Kubernetes, and AI research

**Best for:** AI engineers, ML engineers, and cloud engineers

## 10. Sindre Sorhus: Open Source Development

[GitHub: sindresorhus](https://github.com/sindresorhus)

Sindre Sorhus is one of the most prolific open-source developers in the JavaScript ecosystem.

**Learn from:** JavaScript, TypeScript, Node.js, and open source development

**Best for:** Frontend developers, backend developers, and open source contributors

## 11. freeCodeCamp: Programming Education

[GitHub: freeCodeCamp](https://github.com/freeCodeCamp)

freeCodeCamp is one of the world's largest free programming education platforms.

**Learn from:** Web development, full-stack development, JavaScript, and open source

**Best for:** Beginners, full-stack developers, and students

**Recommended resources:** Responsive Web Design, JavaScript Algorithms, Front End Libraries, and APIs and Microservices

## 12. Real Python: Python Learning Resources

[GitHub: realpython](https://github.com/realpython)

Real Python provides learning resources for Python developers from beginner to advanced level.

**Learn from:** Python basics, automation, APIs, and data processing

**Best for:** Python beginners, automation engineers, and data scientists

## 13. The Algorithms: Algorithms in Multiple Languages

[GitHub: TheAlgorithms](https://github.com/TheAlgorithms)

The Algorithms organization maintains a large collection of algorithms and data structure implementations.

**Learn from:** Data structures, algorithms, problem solving, and competitive programming

**Best for:** SDE interview candidates, software engineers, and students

**Available languages:** Python, Java, C++, JavaScript, and Go

## 14. Donne Martin: Data Engineering & Python

[GitHub: donnemartin](https://github.com/donnemartin)

Donne Martin is known for maintaining useful repositories for software engineers and data professionals.

**Learn from:** Python best practices, system design, software engineering, and data engineering

**Popular repositories:** [system-design-primer](https://github.com/donnemartin/system-design-primer) and [interactive-coding-challenges](https://github.com/donnemartin/interactive-coding-challenges)

**Best for:** Software engineers, data engineers, and SDET engineers

## 15. TensorFlow: Machine Learning Framework

[GitHub: tensorflow](https://github.com/tensorflow)

The TensorFlow organization publishes the official TensorFlow machine learning and deep learning framework.

**Learn from:** Deep learning, computer vision, NLP, and model deployment

**Best for:** ML engineers, AI researchers, and data scientists
