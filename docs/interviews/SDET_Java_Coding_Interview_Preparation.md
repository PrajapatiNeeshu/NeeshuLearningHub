# Top Java Coding Problems for SDET Interviews

If you are preparing for SDET interviews, these are the must-practice coding problems frequently asked in product-based companies and automation-focused roles.

---

# 1. String Manipulation

### Reverse a String
- Reverse a string without using `StringBuilder.reverse()`

### Anagram Check
- Check if two strings are anagrams

### First Non-Repeating Character
- Find the first non-repeating character in a string

### Count Characters
- Count vowels and consonants in a string

### Remove Duplicates
- Remove all duplicate characters from a string

### Unique Characters
- Check if a string contains all unique characters

### String Compression
- Implement basic string compression

Example:

```text
Input:  aabcccccaaa
Output: a2b1c5a3
```

---

# 2. Array / List Problems

### Second Largest Element
- Find the second largest number in an array

### Move Zeros
- Move all zeros to the end of an array

Example:

```text
Input:  [1,0,3,0,5]
Output: [1,3,5,0,0]
```

### Rotate Array
- Rotate an array by K positions
- Right Rotation
- Left Rotation

### Merge Sorted Arrays
- Merge two sorted arrays without using extra space

### Missing Number
- Find missing number from 1 to N

### Array Intersection
- Find intersection of two arrays

### Maximum Sum Subarray
- Find subarray with maximum sum (Kadane's Algorithm)

### Find Duplicates
- Find duplicate elements in an array

---

# 3. Map / HashMap Problems

### First Non-Repeated Element
- Find the first non-repeated element in an array

### Frequency Count
- Count frequency of each element

Example:

```text
Input:  [1,2,2,3,3,3]
Output:
1 -> 1
2 -> 2
3 -> 3
```

### Pair with Given Sum
- Find all pairs with a given target sum

### Group Anagrams
- Group words that are anagrams

Example:

```text
Input:
eat, tea, tan, nat, ate

Output:
[eat, tea, ate]
[tan, nat]
```

### Most Frequent Element
- Find the most frequent element in an array

---

# 4. Linked List Problems

These are frequently asked in FAANG and Product-Based Company interviews.

### Detect Cycle
- Detect a cycle in a linked list using Fast and Slow Pointer Approach

### Find Middle Node
- Find the middle element of a linked list

### Reverse Linked List
- Reverse a linked list

### Merge Sorted Linked Lists
- Merge two sorted linked lists

---

# 5. Pattern-Oriented DSA Problems

## Sliding Window

### Longest Substring Without Repeating Characters

Example:

```text
Input: abcabcbb
Output: 3
```

Longest substring:

```text
abc
```

---

## Two Pointers

### Palindrome Check
- Check if an array or string is palindrome

### Remove Duplicates
- Remove duplicates from sorted array

Example:

```text
Input:  [1,1,2,2,3]
Output: [1,2,3]
```

---

## Binary Search

### Search in Rotated Sorted Array

Example:

```text
Input:
[4,5,6,7,0,1,2]

Target:
0

Output:
4
```

---

## Greedy Algorithm

### Minimum Coins Problem

Example:

```text
Amount = 49

Coins:
20 + 20 + 5 + 2 + 2
```

Find minimum number of coins required.

---

## Backtracking

### Generate Subsets

Example:

```text
Input:
[1,2,3]

Output:
[]
[1]
[2]
[3]
[1,2]
[1,3]
[2,3]
[1,2,3]
```
