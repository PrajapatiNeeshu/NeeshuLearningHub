# Q001 - What is Test Strategy?

A test strategy is the high-level approach an organization follows to test a product. It defines the testing scope, methods, tools, and objectives.

## Key Points
- It is usually created at the project or organization level.
- It includes test levels, environments, and risk coverage.
- It helps teams plan testing consistently.

## Example Answer
Test strategy is a plan that explains how testing will be performed across the project. It defines the testing objectives, test levels, tools to be used, responsibilities, and the overall approach to delivering quality software.
