# Q004 - What is Severity?

Severity describes the impact of a defect on the system or business. It measures how serious the issue is from a technical perspective.

## Common Severity Levels
- Critical
- Major
- Moderate
- Minor
- Low

## Example Answer
Severity tells us how badly a defect affects the application. For example, if an application crashes on login, that is critical severity because it blocks core functionality. Severity focuses on the impact of the defect on the system.
