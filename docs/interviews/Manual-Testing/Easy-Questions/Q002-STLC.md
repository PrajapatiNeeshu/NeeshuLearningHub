# Q002 - What is STLC?

STLC stands for Software Testing Life Cycle. It is the sequence of testing activities performed to ensure software quality from planning to closure.

## STLC Phases
1. Requirement Analysis
2. Test Planning
3. Test Case Development
4. Environment Setup
5. Test Execution
6. Defect Reporting
7. Test Cycle Closure

## Example Answer
STLC is the testing process used to verify that a software system meets the required quality standards. It starts with requirement analysis and continues through planning, designing test cases, executing them, reporting defects, and closing the testing cycle.
