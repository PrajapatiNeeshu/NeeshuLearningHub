# Q001 - What is Manual Testing?

Manual testing is the process of testing software by a human tester without using automation tools. The tester follows test cases, checks UI behavior, verifies expected results, and reports defects.

## Key Points
- It is useful for user experience and UI validation.
- It helps identify issues that are hard to catch with scripts.
- It is ideal for exploratory and ad-hoc testing.

## Example Answer
Manual testing is a type of software testing where a tester executes the application manually to validate whether it works as expected. The tester checks the functionality, looks for defects, verifies business flows, and ensures the product meets user requirements.
