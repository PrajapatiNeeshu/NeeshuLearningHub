# Q003 - What is SDLC?

SDLC stands for Software Development Life Cycle. It is the complete process of building software, starting from requirement gathering to deployment and maintenance.

## SDLC Phases
- Requirement Analysis
- Feasibility Study
- Design
- Development
- Testing
- Deployment
- Maintenance

## Example Answer
SDLC is the end-to-end process used to develop software. It includes planning, designing, coding, testing, deploying, and maintaining the application. Testing is one important part of the SDLC, but SDLC covers the whole software lifecycle.
