# Q002 - Production Bug

## Scenario
A production issue is reported where users are unable to log in after a new deployment.

## Response
- Reproduce the issue in the affected environment.
- Check logs, recent deployment changes, and configuration changes.
- Compare with the last working build.
- Validate whether the bug is caused by code, environment, or data.
- Communicate impact and coordinate with the team for a quick fix.

## Example Answer
A production bug requires immediate investigation because it affects real users. I would first confirm the issue, identify the impacted flow, review recent changes, and analyze environment or configuration issues. Then I would work with developers and release teams to isolate root cause, patch the issue, and validate the fix before re-opening the system.
